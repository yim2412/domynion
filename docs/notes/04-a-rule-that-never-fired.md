# 한 번도 발동한 적 없는 규칙

> Domynion · 2026-09-04 · [`22d1284`](https://github.com/yim2412/domynion/commit/22d1284)

증강 카드는 계수다. 병력 상한 +18%, 정복 비용 −14% 같은 것들이 각자 **축**에 실린다.
설계 문서와 코드 주석이 둘 다 앞자리에 이 원칙을 적어 뒀다:

> **같은 축에 여러 카드가 실리면 더한다**(곱하지 않는다). 곱하면 카드가 쌓일수록
> 체감이 급격해져 후반이 한 명의 독주가 된다.

## 발단 — 한 줄짜리 확인

다음에 카드를 늘린다면 어느 축에 놓을지 보려고 분포를 세어 봤다.

```python
Counter(a.field for a in AUGMENTS)
```

```
축 → 카드 수 : 열 축 전부 1
카드가 둘 이상인 축: 없다
```

카드 10장이 축 10개에 **정확히 하나씩**이었다. 그러니까 위 원칙은
**한 번도 돈 적이 없다.** 쌓이는 것은 레벨뿐이다.

## 그 규칙을 재던 테스트가 이름과 다른 것을 재고 있었다

```python
def test_same_axis_cards_add_not_multiply():
    two = Modifiers.from_augments({"fertile": 2})     # ← 한 장의 Lv2 다
    # 두 장이 같은 축이면 합이다 — 0.18 + 0.18×1.7 이지 곱이 아니다
    assert two.get("troops_cap_pct") == value_at(AUGMENTS_BY_KEY["fertile"], 2)
```

- 재료가 **두 장이 아니라 한 장의 레벨 2** 다.
- 주석의 산수도 틀렸다. `0.18 + 0.18×1.7` 은 **0.486** 인데 실제 값은 **0.306**
  (`0.18 × 1.7`)이다.
- 단언이 `value_at` 을 쓰고 있어서 **틀린 주석과 함께 통과**하고 있었다.

## 변이 하나가 살아남아 그 다음을 짚어 줬다

이 프로젝트는 소스를 일부러 깨뜨려 테스트가 잡는지 재는 하네스를 쓴다.
합산 코드를 **덮어쓰기**로 바꾸는 변이를 넣었더니 `SURVIVED` 가 나왔다.

```python
values[field] = values.get(field, 0.0) + value_at(aug, level)
#             → values[field] = value_at(aug, level)
```

**두 구현의 동작이 같다.** 축마다 카드가 하나뿐이라 `values.get(field, 0.0)` 이
늘 0.0 이고, `0.0 + x == x` 다.

그리고 그 사이 내가 새로 쓴 테스트도 못 잡았다 — `Modifiers({...})` 를 **손으로**
만들어서 합산 코드를 아예 안 탔기 때문이다.

합성 카드 하나를 임시로 얹어 **같은 축 두 장**을 만들고 나서야 잡혔다.

```python
extra = Augment("second_cap", "합성 카드", ..., "troops_cap_pct", 0.10)
monkeypatch.setitem(AUGMENTS_BY_KEY, extra.key, extra)
m = Modifiers.from_augments({"fertile": 1, extra.key: 1})
```

## 잠든 규칙을 지우지 않고 못 박았다

규칙을 지울 수도 있었지만, 카드를 늘리면 되살아날 규칙이다. 대신 **깨어나는
순간을 알리는 테스트**를 뒀다.

```python
def test_every_axis_has_exactly_one_card_so_the_add_rule_is_dormant():
    ...
```

열한 번째 카드를 이미 있는 축에 얹는 순간 이 테스트가 깨진다. 깨졌을 때 고칠 것은
**이 테스트가 아니라 설계 문서의 할인 중첩 계산**이다 — 그 절은 *"할인 카드가
축마다 하나뿐"* 을 전제로 쓰여 있다. 그 사실을 실패 메시지에 적어 뒀다.

## 이 건에서 남긴 규칙

> **문서가 앞자리에 적어 둔 규칙일수록 의심한다.** 앞자리에 적혔다는 것은
> 중요하다는 뜻이지 **돈다는 뜻이 아니다.**

같은 날 같은 모양을 하나 더 만났다 — 할인 하한(`max(0.2, …)`)도 **카드로는 절대
닿을 수 없는 값**을 막고 있었다. 보호 장치가 있고, 그 장치를 재는 테스트도 있고,
**그 상황이 게임에서 일어날 수 없었다.**

> *"막지 않았으면 무엇이 일어났을 것인가"* 를 단언해도 빠져나간다.
> 빠진 것은 다음 질문이다 — **"그 일이 이 게임에서 실제로 일어날 수 있는가."**
